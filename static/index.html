⚙ Connect YouTube (OAuth Setup)

To upload directly to your channel, Google requires a free OAuth Client ID from Google Cloud Console.

Quick Setup (2 minutes):
1. Go to Google Cloud Console → Credentials.
2. Create OAuth 2.0 Client ID (Application type: Web application).
3. Set Authorized redirect URI to:
http://localhost:8000/api/youtube/oauth2callback
